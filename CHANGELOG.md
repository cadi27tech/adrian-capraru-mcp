# Changelog

## 1.0.0 - 2026-10-27

First release.

- Six read-only tools over stdio: `get_profile`, `list_case_studies`, `get_case_study`, `list_services`, `check_availability`, `how_to_hire`.
- `data/profile.json` generated by `scripts/build-data.mjs` from the website's own data (`content.mjs`, `resume.json`, the contact page) and the published Upwork offers. Content rules fail the build on a banned fact, a dash other than the ASCII hyphen, an email address or first-person copy.
- `availability.json`, a status edited by hand and read on every call.
- 10 tests that start the server and call every tool; CI on Node 20 and 22.
- MCPB bundle attached to the release, listed in the official MCP Registry as `io.github.cadi27tech/adrian-capraru`.
